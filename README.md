# ☕ BREWVERSE – Smart Coffee Rating & Voting Platform

### Discover. Vote. Enjoy.

BREWVERSE is a modern Coffee Rating and Voting Platform that allows users to explore different coffee varieties, vote for their favourite drinks, share reviews, and discover trending coffees.

The platform combines an interactive user experience with backend functionality and database-driven voting.

---

## 🚀 Features

- ☕ **Coffee Collection** – Explore different coffee varieties.
- 👍 **Interactive Voting** – Vote for your favourite coffee.
- 🏆 **Live Leaderboard** – Discover the most popular coffees.
- ⚔️ **Coffee Battle** – Compare two coffees and choose the winner.
- ⭐ **Ratings & Reviews** – Share coffee experiences.
- ❤️ **Favorites** – Save your favourite coffee varieties.
- 📊 **Voting Analytics** – Visualize voting statistics.
- 🔍 **Smart Search** – Search and filter coffee varieties.
- 🎯 **Coffee Personality Finder** – Get personalized coffee recommendations.
- 🎲 **Random Coffee Generator** – Discover a surprise coffee.
- 🌙 **Dark/Light Mode** – Switch between themes.
- 📱 **Responsive Design** – Accessible across different devices.

## ⚙️ Installation & Setup

### 1. Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/BREWVERSE-Coffee-Rating-Application.git
```

### 2. Open Project

```bash
cd BREWVERSE-Coffee-Rating-Application
```

### 3. Install Backend Dependencies

```bash
cd backend
npm install
```

### 4. Configure Environment Variables

Create a `.env` file inside the backend folder.

```env
PORT=5000
MONGO_URI=mongodb://127.0.0.1:27017/brewverse
JWT_SECRET=your_secret_key
```

### 5. Start Backend

```bash
node server.js
```

### 6. Run Frontend

Open another terminal:

```bash
cd frontend
npm install
npm run dev
```

Open the local URL displayed in your terminal.

**Note:** The commands assume your frontend uses Vite and your backend uses `server.js`. Adjust them if your actual project scripts differ.
